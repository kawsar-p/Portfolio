# Md. Kawsar Miah — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Files

- `index.html` — Main portfolio page
- `style.css` — Complete styling, theme and responsive/mobile layout
- `script.js` — Theme switcher, Bangla/English language switcher, mobile menu, reveal animation and View More Projects functionality
- `README.md` — Project documentation

## Features

- English / Bangla language toggle
- Correct Bangla name: `মোঃ কাওছার মিঞা`
- Dark / Light theme
- Responsive navigation with mobile menu
- Responsive hero, skills, projects, research and contact sections
- First 4 projects visible by default
- Additional projects shown with **View More Projects**
- GitHub, LinkedIn and email links
- Gmail compose link for contacting via email
- Mobile-friendly buttons, cards and typography
- Small-screen support down to 380px

## Run locally

1. Keep all four files in the same folder.
2. Open `index.html` directly in a browser, or use VS Code Live Server.
3. If the browser shows an older version, use `Ctrl + F5`.

## GitHub Pages

Upload/replace these files in your repository:

- `index.html`
- `style.css`
- `script.js`
- `README.md`

Then wait for GitHub Pages to redeploy and refresh the site.
